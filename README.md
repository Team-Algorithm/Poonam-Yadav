## 📌 Project Context & Overview

**ReleaseShield AI** is an enterprise-focused security pipeline designed to standardize security scanner outputs across software development lifecycles.

### What We Are Building
* **Data Normalization:** Ingesting raw security findings from various SAST and DAST tools and normalizing them into the standard **SARIF v2.1.0** schema.
* **Deterministic Fingerprinting:** Generating reliable `partialFingerprints` (including secret hashing across Git branches) to track vulnerability persistence over time.
* **Repository & Code Ownership Integration:** Mapping findings to CODEOWNERS file precedence and facilitating automated GitHub repository processing and security checks.
